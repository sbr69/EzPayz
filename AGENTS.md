# Agent Instructions

Always think like a senior developer before proceeding with anything. Never do any guess work, only proceed when 100% sure. ask me even if you have 1% doubt in anything anywhere. Dont do anything by yourself if anything is not in the plan. just lemme know if you are stuck anywhere or have any doubt. dont make core decisions by yourself

## Decision-making and execution

- Always think like a senior developer before proceeding with any task.
- Do not guess, infer unstated requirements, or make assumptions. Verify facts from the repository, documentation, or reliable sources.
- Before taking action, ensure the requested behavior, scope, and implementation path are fully understood.
- If there is even minor uncertainty or more than one reasonable interpretation, stop and ask the owner for clarification.
- Do not make core architectural, product, security, or behavioral decisions independently. Present the options and wait for the owner's decision.
- Do not do work that is not explicitly included in the approved plan or request.
- If the task conflicts with `PLAN.md`, stop and ask the owner before changing the plan or implementation.
- If blocked, stuck, or unable to verify something, report it clearly and wait for guidance.

## Changes and validation

- Make only the requested, planned, and verified changes.
- Preserve existing behavior unless a change is explicitly approved.
- Before editing, inspect the relevant code and existing conventions.
- Report assumptions, uncertainties, blockers, and validation results explicitly; do not silently fall back or proceed with an unverified alternative.
